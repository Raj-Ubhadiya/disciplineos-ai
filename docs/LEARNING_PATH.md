# Learning Path

This project is designed so you can learn the stack while building the product.

## 1. Monorepo

Learn:

- What `apps` and `packages` mean.
- How frontend, backend, and shared packages live together.
- How pnpm workspaces connect everything.

## 2. NestJS

Learn:

- Modules
- Controllers
- Services
- DTOs
- Guards
- Dependency injection

## 3. Prisma And PostgreSQL

Learn:

- Prisma schema
- Database models
- Migrations
- Relations
- CRUD queries

## 4. Next.js

Learn:

- App Router
- Server Components
- Client Components
- Forms
- Fetching backend data

## 5. Authentication

Learn:

- Password hashing
- JWT tokens
- Protected routes
- Authenticated frontend sessions

## 6. AI Integration

Learn:

- Backend AI endpoints
- Prompt design
- Storing generated plans
- Making AI outputs useful and practical
