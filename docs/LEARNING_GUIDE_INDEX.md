## What Each File Is For

### `PRODUCT_ROADMAP.md`

Explains the startup/product idea, app vision, modules, and future versions.

Use this when someone asks:

- What problem does your project solve?
- Who are the users?
- What is the product vision?
- How will this become a real startup?

### `LEARNING_PATH.md`

Explains what to learn first and in what order.

Use this when you feel confused about the stack or want to revise basics.

### `PROJECT_STRUCTURE_AND_CONFIG_GUIDE.md`

Explains monorepo folders and config files like:

- `package.json`
- `pnpm-workspace.yaml`
- `tsconfig.json`
- `eslint.config.mjs`
- `.prettierrc.json`
- `docker-compose.yml`

Use this for interview questions about project structure and configuration.

### `TECH_STACK_DEEP_DIVE.md`

Explains each major technology:

- Next.js
- React
- NestJS
- Prisma
- PostgreSQL
- JWT
- bcrypt
- Docker
- pnpm monorepo
- TypeScript
- ESLint
- Prettier
- Zod

Use this when you want to understand why each technology is used and what alternatives exist.

### `IMPLEMENTATION_PLAYBOOK.md`

Explains how we implement features in this project step by step.

Use this when building new modules like:

- Goals
- Habits
- Distractions
- AI planner
- Accountability partner management

### `INTERVIEW_QA.md`

Contains common interview questions and strong answers based on this project.

Use this before interviews.

### `DEPLOYMENT.md`

Explains frontend, backend, and database production deployment.

Use this when preparing the project for launch or explaining production readiness.

### `PRODUCTION_CHECKLIST.md`

Lists the checks to complete before a real deployment.

Use this as a final release checklist.

### `NEON_RENDER_VERCEL_RUNBOOK.md`

Explains the selected production deployment path using Neon, Render, and Vercel.

Use this while launching the app.

## How To Use These Files

Read one file per day and revise the code beside it.

Suggested method:

1. Read the concept.
2. Open the related code file.
3. Trace request flow from frontend to backend.
4. Write a short explanation in your own words.
5. Practice answering interview questions out loud.
