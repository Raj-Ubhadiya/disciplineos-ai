# DisciplineOS AI - Product Roadmap

## Vision

DisciplineOS AI helps people reduce social media distraction, stay focused on their goals, build daily discipline, and manage partner accountability with AI-guided planning and reflection.

## MVP Loop

User signs up, defines a dream, creates goals, tracks habits, logs distractions, and receives AI guidance to stay consistent.

## Core Modules

- Authentication
- User profile
- Goals
- Habits
- Reminders
- Distraction logs
- AI goal planner
- Accountability partners
- Analytics dashboard

## Phase Plan

### Version 0.1 - Foundation

- Monorepo setup
- Next.js app
- NestJS API
- Prisma/PostgreSQL setup
- Shared types and config

### Version 0.2 - Auth And Profile

- Signup/login
- JWT auth
- User profile
- Protected API routes

### Version 0.3 - Goals And Habits

- Goals CRUD
- Habits CRUD
- Habit completion tracking
- Dashboard checklist

### Version 0.4 - AI Planner

- AI-style goal breakdown
- Weekly plan generation
- Save generated plans in PostgreSQL
- Later convert suggestions into goals/habits

### Version 0.5 - Distraction Reduction

- Social media distraction logs
- Trigger patterns
- Replacement action suggestions

### Version 0.6 - Accountability Partner Management

- Accountability partner profile
- Shared discipline goals
- Partner check-ins
- Commitment reminders
- Goal sharing with partner ownership checks

### Version 1.0 - Portfolio MVP

- Full demo flow
- Polished dashboard
- Analytics and focus score
- Today focus plan
- Daily reflections
- Focus session tracking
- Integrated analytics signals
- API docs
- README screenshots
- Deployment guide
